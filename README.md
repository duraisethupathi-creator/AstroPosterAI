# AstroPoster AI

Tamil-first AI content and poster studio for astrologers.

## Stage 1
- React Native + TypeScript mobile foundation
- Tamil / English localization
- Premium home dashboard
- Brand Profile foundation
- Astrology poster category flows
- Poster editor foundation
- Settings and AI provider architecture for OpenAI + Gemini

> API secrets must never be stored in the mobile application. AI calls will be routed through a secure backend in a later implementation stage.
